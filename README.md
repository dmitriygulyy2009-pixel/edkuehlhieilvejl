# Iron Rhythm — как собрать APK

1. Создайте на github.com новый репозиторий (можно приватный).
2. Распакуйте архив и загрузите ВСЁ содержимое в репозиторий (папка .github тоже должна попасть — она скрытая).
   Проще всего: «Add file → Upload files» и перетащить всё, включая папку .github.
3. Откройте вкладку Actions → "Build APK" (запустится сам после загрузки, либо Run workflow).
4. Через ~5 минут откройте завершённый запуск → внизу «Artifacts» → IronRhythm-apk → скачайте, распакуйте, установите app-debug.apk на телефон.

Обновления: загрузили новые файлы — собрали — установили поверх. Ключ подписи фиксированный (debug.keystore), поэтому данные не теряются.
Экспорт/импорт прогресса: Настройки → Экспорт / Импорт. Старые файлы прогресса принимаются всегда.
